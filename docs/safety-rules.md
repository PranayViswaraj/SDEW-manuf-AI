# Safety rules (non-negotiable)

Each rule is enforced in code and has at least one automated test. Updated every milestone.

Role checks on **every** endpoint: `server/tests/test_route_roles.py` — every API route must be
declared with its allowed roles, or the test suite fails.

| # | Rule | Enforced in | Tests |
|---|------|-------------|-------|
| 1 | Software never replaces the physical emergency stop. No button is ever presented as an emergency stop. | Web UI: E-stop reminder on Home and on every run screen; no button text mentions E-stop/emergency; the run screen's Stop button is labelled as a control reset, "NOT an emergency stop" | `web/tests/App.test.tsx` "never shows anything labelled as an emergency stop button", `web/tests/run.test.tsx` "no button is presented as an emergency stop" |
| 2 | The AI never writes or edits CNC programs. Program generation is deterministic code only. | `ProgramSource` has no AI source; `program_store.create_version` refuses unknown sources; validator is fixed rules (`server/app/gcode/validator.py`); `ProgramGenerator` (M12) | `server/tests/test_programs.py::test_program_sources_never_include_ai` |
| 3 | No program is sent unless the feature table is engineer-confirmed AND the program is programmer-approved for that exact part + machine + program version (content hash). | `server/app/services/approval.py: approval_problem` (approved status, same machine, approved hash == text hash, latest version, still validates); text changes create a new version and retire the approved one (`program_store.create_version`); `feature_tables.feature_table_problem` (engineer-confirmed, unchanged since confirmation); both re-checked by `run_service.send_blockers` and passed as gates to `run_control`; bridge rejects a `send_program` whose text does not match the signed hash | `server/tests/test_runs.py::test_lmw_run_needs_feature_table_and_cycle_start_at_machine`, `server/tests/test_programs.py::test_approval_problem_rules`, `::test_approve_then_edit_creates_new_version_and_clears_approval`, `::test_approve_requires_no_errors`, `bridge/tests/test_actions.py::test_hash_mismatch_rejected`, `::test_bad_signature_rejected` |
| 4 | Start unlocks only when: every checklist item ticked this session, no alarm, machine idle, approved program loaded, user on the allowed-to-start list. | `users.can_start_machine` (M2); `run_control.permission_problem` (operator + allowed-to-start); bridge `_start` re-checks idle / no alarm / no E-stop / MEM mode / verified program + hash selected (M8); `run_service.start_blockers`: checklist for THIS run, fresh status, idle, no alarm, no emergency, verified program loaded, allowed-to-start list, remote control (M11); web Start button disabled with reasons | `bridge/tests/test_actions.py::test_start_runs_only_verified_selected_program`, `::test_start_rechecks_machine_state`, `server/tests/test_e2e_bridge.py::test_start_needs_allowed_to_start_list`, `server/tests/test_runs.py::test_start_lock_conditions`, `::test_start_locked_when_bridge_offline`, `::test_each_checklist_item_is_required`, `web/tests/run.test.tsx` |
| 5 | The bridge connects **outward only**. It never opens a listening port. | `bridge/bridge/config.py` (ws/wss URL only); `bridge/bridge/ws_client.py` uses an outbound client only; server endpoint `server/app/api/bridge_ws.py` | `bridge/tests/test_config.py::test_server_url_must_be_outbound_websocket`, `server/tests/test_e2e_bridge.py` (bridge dials the server) |
| 6 | The bridge accepts only `send_program`, `start`, `feed_hold`, `stop`, `read_status`. Anything else is rejected and logged. | `bridge/bridge/actions.py` (`ALLOWED_ACTIONS`, signature, expiry 10 s, replay, machine, hash; rejections logged to the rotating bridge log and acked); server mirror in `run_control.ALLOWED_ACTIONS` | `bridge/tests/test_config.py::test_action_allow_list_is_exact`, `bridge/tests/test_actions.py` (unknown action, signature, expiry, replay, wrong machine, hash), `bridge/tests/test_ws_client.py::test_non_command_messages_are_ignored` |
| 7 | Every action is logged (user, machine, program, hash, action, result, timestamp). The log is append-only. | `server/app/services/audit_log.py` (own session, committed immediately); `server/app/db/guards.py`; DB triggers (migration `0002_users_audit`); `run_control` writes "requested" BEFORE acting and the result after; bridge connect/disconnect/auth audited | `server/tests/test_audit_log.py`, `server/tests/test_e2e_bridge.py::test_send_program_end_to_end_with_readback` (requested + ok rows), `server/tests/test_runs.py::test_full_simulated_run_with_remote_start` (every run step audited) |
| 8 | If the bridge loses the server it takes no machine action on its own. UI shows stale/offline after 5 s without updates. | `bridge/bridge/ws_client.py` (acts only on received commands, queues nothing, late commands expire); `server/app/services/bridge_hub.py` live states; web `LivePanel` / `LiveBadge` | `bridge/tests/test_ws_client.py::test_no_machine_action_while_server_unreachable`, `::test_late_command_after_reconnect_is_rejected_not_executed`, `server/tests/test_bridge_hub.py::test_states_online_stale_offline`, `server/tests/test_e2e_bridge.py::test_status_flows_and_goes_offline_when_bridge_stops`, `::test_nothing_sent_while_bridge_offline`, `::test_bridge_reconnects_after_connection_drop`, `web/tests/live.test.tsx` |
| 9 | `start`, `feed_hold`, `stop` are disabled by default (`remote_control_enabled: false`). When disabled, the UI shows "Press Cycle Start at the machine". | Run screen hides Start/Feed hold/Stop and shows "Program sent. Press Cycle Start at the machine." when off; bridge config default false + PMC address required (drivers); server `machines.remote_control_enabled` default false, changes audited; `run_control` refuses remote actions when off; bridge refuses when its own config is off | `bridge/tests/test_config.py::test_remote_control_disabled_by_default`, `bridge/tests/test_simulated_driver.py::test_remote_control_disabled_by_default`, `bridge/tests/test_focas_driver.py::test_remote_control_off_by_default`, `bridge/tests/test_actions.py::test_remote_actions_rejected_when_remote_control_off`, `server/tests/test_machines.py::test_new_machine_defaults_are_safe`, `server/tests/test_e2e_bridge.py::test_remote_start_refused_when_disabled` |
