# Simulator demo program

`O9000` is a **synthetic program for the simulated lathe only — NOT FOR MACHINE USE.**
It is not a company program and was never proven on a real machine. It exists so the
simulator, the run screen and the backplot can be demonstrated on a fresh install.

The dev seed registers it only for the dev machine "SIM Lathe (dev)", never for LMW Lathe 1.
